# ItemLoader
yamlファイルで書いたアイテムの設定からItemStack変換させるプラグインです。
他のプラグインへの提供を行うライブラリプラグインです。


---

## フォルダ構成と配置ルール

プラグインのデータフォルダ（`plugins/ItemLoader/data/`）以下であれば、**フォルダ名や階層の深さに制限はありません**。管理しやすいように自由にフォルダを分けて分類してください。

**配置例:**
```text
plugins/ItemLoaderAPI/
  └── data/
      ├── weapons/                  # 武器カテゴリ
      │     └── swords.yml          # 剣の設定ファイル
      ├── dungeons/                 # ダンジョン関連
      │     └── tier1_rewards.yml   # 報酬アイテムの設定ファイル
      └── custom_materials.yml      # ルート直下に直接ファイルを置いても大丈夫です
```

---

## 設定ファイルの記述方法（YAML）

設定ファイル内の**最上段のキー（階層の分かれ目）が、サーバー内で唯一の「識別ID」**になります。
この「識別ID」は、他のファイルや他のフォルダにあるアイテムも含めて、**絶対に重複しないユニークな名前**にしてください。

必須項目は**識別ID** 、**Material** です。
この2つの項目がないとそもそもアイテムが登録されないため注意してください。

### アイテムの設定例 (`sample.yml`)

```yaml
# ==================================================================
# ItemLoaderAPI カスタムアイテム設定サンプル
# ==================================================================

# 識別ID（アイテムの固有IDです。他と絶対に被らない名前にしてください）
excalibur:
  
  # 材料名
  material: DIAMOND_SWORD
  
  # 個数（デフォルトは1です）
  amount: 1
  
  # アイテムの表示名
  name: "§5§lテスト剣1"
  
  # アイテムの説明文（ Lore ）
  lore:
    - "§2試しに作られたアイテム！！"
    - ""
    - "§6テストの剣"
  
  # エンチャント（「名前:レベル」または「名前空間:名前:レベル」の形式）
  # 存在しないエンチャント名や、レベルに文字を書いた場合はアイテムの登録は行われず、コンソールに警告が出ます。
  enchants:
    - SHARPNESS:5
    - UNBREAKING:3
    - minecraft:fire_aspect:2

  #  耐久・強度に関する設定
  durability:
    # 真偽値（true / false）で指定します。
    unbreakable: true

  # 見た目に関する設定
  model:
    # カスタムモデルデータ
    custom-model-data: 12345
    # アイテムモデルデータを使う場合
    item-model: "custom_items:weapons/excalibur"

# 最低限マテリアルさえ書かれていれば、これだけでシンプルなアイテムとして登録可能です
simple_stone:
  material: STONE
```

## アイテムファイル上でのエラーについて

設定ファイルの記述ミスがあった場合、本プラグインはサーバーの起動を妨げず、原因を分かりやすくコンソールに出力して該当アイテムのみを安全にスキップします。

### 1. YAMLの構文エラー
スペースの数がズレているなど、ファイル自体が壊れている場合は、エラーが起きた**ファイルパスと行数**を特定して出力します。

### 2. 設定内容のミス
`material` が書かれていない、材料名が間違っている、または識別IDが他のファイルにあるアイテムと重複している場合は、**【設定ミス】**として警告が出力されます。

ただし、項目が存在しない場合は読み取ろうとしないためエラーも出ません

##  コマンドリスト

| コマンド | 説明 |
| :--- | :--- |
| `/itemloader reload` | `data/` フォルダ内の全設定ファイルを再読み込みします。|
| `/itemloader give <プレイヤー名> <識別ID>` | 指定されたIDのアイテムを指定したプレイヤーに与えます |
